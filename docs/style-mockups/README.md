# 스타일 비교 목업 (Style Study)

게임 비주얼 방향을 정하기 위한 **동일 장면·두 스타일** 비교 컨셉 목업입니다.
실제 Kenney 에셋 스크린샷이 아니라, 같은 항구 장면을 두 렌더링 스타일로 그려
**차이만** 보여 주기 위한 그림입니다(외부 라이브러리 없이 순수 파이썬으로 렌더).

- `style_compare.png` — 좌(벡터/플랫) · 우(픽셀아트) 나란히 비교
- `style_vector.png` — 벡터/플랫 단독 (Kenney *Shape/Flat* 계열 무드)
- `style_pixel.png` — 픽셀아트 단독 (Kenney *Tiny/1-Bit* 계열 무드)
- `generate.py` — 위 이미지를 재생성하는 스크립트 (`python3 generate.py`)

## 장면 구성 (두 스타일 공통)
세로 9:16 모바일 화면 / 탑다운 항구 1곳.
- 상단 HUD: 현재 항구 칩 + **13개 항구 진행 점**(앞 3개 완료)
- 부두에 정박한 **검은 깃발의 배(= 해적선, 반전 복선)**
- **말풍선(NPC 대사)** — 본문은 회색 바로 표현
- 등불 든 **안내자 NPC**(매 항구마다 "예수님을 가리켜요"를 전함)
- 시대 인물 NPC, 플레이어 캐릭터
- 좌하단 **가상 조이스틱**(위로 미는 상태, 위/아래 화살표) · 우하단 진행 버튼
- 수평선 멀리 **밝은 구조선**(엔딩에 갈아탈 배)
