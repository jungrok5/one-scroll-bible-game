# 에셋 출처 / 라이선스

## 현재(플레이스홀더)
`assets/sprites/*.png` 는 **임시 플레이스홀더**입니다 — 게임이 바로 돌아가도록
`tools/gen_assets.py`(순수 파이썬)로 직접 생성한 픽셀 스프라이트(자체 제작, 자유 사용).

## 교체 계획 — Kenney (CC0)
정식 아트는 **Kenney.nl 픽셀 팩(모두 CC0/퍼블릭 도메인)**으로 교체 예정. 후보:
- Tiny Town / Tiny Dungeon (캐릭터·타일·소품)
- 1-Bit Pack (방대한 탑다운 타일셋)
- Pirate Pack (배·해적·물·섬)
- Onscreen Controls (가상 조이스틱)
- UI Pack (말풍선·버튼)
교체 시 파일명을 동일하게 맞추면 코드 수정 없이 바로 반영됩니다(`scripts/` 의 load 경로).
Kenney 에셋은 CC0라 별도 표기 의무는 없으나, 감사 차원에서 출처를 남깁니다.
